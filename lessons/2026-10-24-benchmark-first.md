# 先拆对标，再动手

## 事件
做动效时没打开仓库里现成的参考实现（47 个元素）和 152 张镜头卡，
凭想象做了「一张图 + 推拉」，结果被一眼看出是幻灯片。

## 硬规矩
动手前必须量出四个数字，**拆不出数字不许开工**：

| 指标 | 怎么量 |
|---|---|
| 元素数 | 一个 4–5 秒节拍里有几个独立运动对象 |
| 运动类型数 | 位移/旋转/缩放/透明度/遮罩/路径/逐字… 用了几种 |
| 转场方式 | 淡入淡出 / 接力点 / 遮挡 / 擦除 / 同形状 |
| 动作节点密度 | 每 N 秒有几个「状态变化」 |

## 下限
- 4–5 秒节拍：**≥8 个独立运动元素**（<5 个基本等于幻灯片）
- 同一节拍内至少 3–4 个动作节点，不是一次匀速推拉

## 反例
整张图只做 `scale` / `translate` = 幻灯片，不算动画层。
