# 「负重进化论」文字口径（给 Rio 的同步件）

> 2026-10-14 · 来源：用户真实口播转写（第 2 篇母版 3333 字）＋ 用户自写稿（第 3、9 篇 2980 字）实测。
> 适用范围：**所有卡面大字、标签、标题、发布文案、字幕校对**。口播原话不改，但**你自己写的每一个字都要过这一遍**。

---

## 一、句子的样子

| 规则 | 数字/判据 |
|---|---|
| **短句为主** | 平均句长 **19 字**以内；≤8 字的短句要占 **两成以上**；允许 3–5 字独立成行（"先找教程。""然后收藏。""忘了。"） |
| **转折只用「但／但是」** | 禁用「然而／不过／虽然」；**「而且」基本不用**（实测全样本只 1.6 次/万字）；写大字时更不该出现 |
| **限定词** | 不确定用 **可能／其实／反而／到底**；强调用 **真正** |
| **不靠语气词** | 「吧」「呀」**0 次**；口语感来自短句＋转折＋追问，不是加语气词 |
| **设问** | 每 10–12 句放一个问句；要用**当事人心里的话**（"我应该做哪个呢？"），不要作者式设问 |
| **句子落点** | 落在**动作或短问句**上（…倒出来／…下结论／…是什么）；不落在抽象名词上（…的能力／…的价值） |
| **人称** | 口播主语是「我」；对观众说「你」；**指 AI 一律用「它」**（字幕上会看出来，"他/它"混用是事故） |

## 二、数字与比喻

- **数字只用量级词**：20 多年、100 条、30 个建议、72 分、五到十轮。
  ❌ 不要写精确到小数、带百分号位的数据，除非用户原话里就有。
- **比喻只从生活取**：看病、吃药、药方、症状、收藏夹、买菜、饭桌、陪练。
  ❌ 不要用商业模型、技术架构、算法名词做比喻。

## 三、标题（发给用户的每一条都要按这个写）

1. 写**观众的处境**，不写"我干了什么"。
   ❌《我做门店诊断，发现…》 ✅《别急着 AI 赋能企业，先找到问题在哪》
2. 发稿前三检：**有没有数字？有没有反直觉？跟普通人有没有关系？**
3. 句式参考（对标语料命中率最高的几类）：`为什么/原因`、`怎么/如何`、`别再…`、`越…越…`、`方法都试了一遍，钱也花了，为什么还是没效果？`

## 四、卡面文字（大字/标签）

- **全部真字渲染**，不许 AI 画中文；卡上每个字都要能逐字读清。
- 大字 ≤ 12 字，一行一意；标签 ≤ 6 字。
- **背景文字 ≠ 字幕**：卡面只放**关键词与结论**；底部字幕保持**口播原话一字不改**，两者禁止说同一句。
- 字色/底色按既有规范（深蓝 `#1E3A5F` + 暖白 `#F5F7FA` + 强调橙 `#E06000`），**不用 emoji**。

## 五、发布文案（每条必须带）

```
Kent（负重进化论）｜某央企管理者，23 年产业经验
#负重进化论 #AI #普通人的AI（3–5 个，别堆到 8 个）
```
- 抖音版：**前两行就是最狠的钩子**，只带 3 个标签。
- 视频号版：可以长一些，但第一句仍是处境。

## 六、系列固定件（不许改）

- **收尾签名（口播最后一句，全系列统一）**：`46 岁，AI 让我重新发现自己。`
- **CTA 三件套**（每条片子都要有）：① 一句观众能直接抄的话 ② 下期预告（给具体价值）③ 互动引导（求"说话"不求"关注"）

## 七、红线（违反即返工）

1. **不许自编对话、自编例句、自创口播**——只能用用户真实说过的话。
2. **不许出现**真名、单位全称/简称、具体职务、可识别地名。
3. 引用原话**一字不改**；要改先问。
4. 交付时报**实测值**（时长/帧数/空档/占比），不许报估算或"看起来没问题"。
