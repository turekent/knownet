# 切片选段规范 v2（源头版）· 给 Rio 的切片 agent

> 2026-10-13 · 用户口径原话：「**是不是从源头上考虑，就是切的时候就考虑你提及的问题，而不是在切完的片段里想补救**」
>
> 🔴 **所以：选段的时候就必须挑"自己就是一个完整小故事"的窗口。片头卡/结尾卡不是补救手段——切对了就不需要它。**

---

## 一、选段四问（每一问都必须过，过不了就**换窗口**，不许加卡补救）

1. **第一句能不能独立成立？**
   ❌ 不能用这些起头：`那后来` `所以现在` `这其实也是` `这个时候` `然后我又接着` `是的`
   ✅ 第一句本身就要让人听懂（一个场景、一句提问、一个现象、一个判断）
2. **结尾落在完整句/金句上？**
   ❌ 不许切在半句（例：`…假大空的套话，` ✗ → 要延到 `…一点用都没有。` ✓）
3. **中间有推进？** 至少走完一条链：
   `问题 → 追问 → 答案` ／ `现象 → 反常识 → 结论` ／ `做法 → 结果 → 金句`
4. **15–45 秒能讲完？**（12–15 秒的短句条也可以，但不能更短）

> 四问全过 → 直接切，不加任何卡。四问有一条不过 → **往前扩到有场景/提问的那句，或往后延到结论那句**。

## 二、8 条全部重选（按**句子**定位，不按秒；秒数让 Rio 自己对齐）

| # | 切片 | 起句（第一句） | 止句（最后一句） | 时长约 | 为什么这样切就能独立站住 |
|---|---|---|---|---|---|
| c01 | 假大空套话没用 | 前一天我有个朋友，他找我帮忙做一个实施方案 | …但就是**假大空的套话，一点用都没有** | ~20s | 完整故事：有人求、AI 交、结果没用 |
| c02 | 自己都没想明白 | **你做这件事情的目的是什么？** | 因为我自己都没有想明白 | ~36s | 从第一个提问起 → 走到顿悟，提问本身就是开场 |
| c03 | 答案再漂亮也没意义 | 以前我们做工作，很多时候遇到问题，我们就会马上去找资料、找模板、找专家 | 问题如果没有定义清楚，**这个答案再漂亮也没有意义** | ~20s | 现象 → 结论，自己闭环 |
| c04 | 苏格拉底提问法 | 我碰到这种比较重要的问题，**我不会马上让 AI 给我答案** | 真正卡住我的问题，其实并不是原来那个问题 | ~24s | 做法 → 结果（**去掉"所以现在我们养成了一个习惯"这种承接起头**） |
| c05 | 重复过去 | 因为工作的时间越长，经验越多，有时候反而容易凭经验下结论 | 其实我们都以为自己是在判断，**但是很多时候我们是在重复过去** | ~16s | 因果 + 金句收尾 |
| c06 | 好问题更有价值 | 卡住的时候，很多时候不是不会做，而是我们没有想清楚要做什么 | **一个好问题，比十个答案更有价值** | ~18s | 观点 → 金句（**把"工作了20多年/重新发现自己"那段口号留给主片，不要带进来**） |
| c07 | 一点一点逼出来 | 我以前总觉得，它最大的价值是它帮我做 | 它能把我脑子里那些模糊的东西，**一点一点逼出来**（可延一句：这对工作了 20 多年的人特别重要） | ~13–17s | 观点反转，自己成立 |
| c08 | 脑子倒出来 | **它像一个不懂人情世故、但特别爱问问题的年轻小伙子** | 它并没有耽误你的工作，**它是帮你把脑子里面的东西倒出来** | ~20s | 比喻 → 结论（**现在的版本断在"不"字上，必须从这里改**） |

**跟旧版的差别（都因这条原则）**：
- c02 从「那后来我就开始问他」→ 改从「你做这件事情的目的是什么」起（承接词不要）
- c04 从「所以现在我们已经为自己养成了一个习惯」→ 改从「我不会马上让 AI 给我答案」起
- c06 从「所以我现在越来越相信一句话」→ 改从「卡住的时候…」起，并**去掉口号段**
- c07 从「这其实也是我为什么现在越来越」→ 改从「我以前总觉得…」起
- c08 从「这个时候反而就很像一个不」→ 改从「它像一个…」起
- c01 结尾从半句「假大空的套话，」→ 延到「一点用都没有」
- c03/c05 起止都收在完整句上（原来时序对但进出点要重新对齐句子边界）

## 三、交付时每条必须报（自检门槛）

- [ ] **第一句原文**（贴出来，确认里面没有 `那后来/所以现在/这其实也是/这个时候` 这类承接词）
- [ ] **最后一句原文**（贴出来，确认是完整句）
- [ ] 实测时长（15–45s；短句条 12–15s 也算过）
- [ ] 是否加了卡：**默认不加**；只有确实需要补品牌标识时才在**最后 1.5s** 放品牌卡，不要用片头卡去遮承接词
- [ ] 取段秒数（对齐成片 v6 时间轴）

## 四、唯一保留的包装动作

- 结尾 **1.5s 真字品牌卡**（`负重进化论` + `想不通的事，评论区告诉我`）——**要或不要由用户定**，不是补救，是统一品牌露出
- 不加片头卡（切对了就不需要）
