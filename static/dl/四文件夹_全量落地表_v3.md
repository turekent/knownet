## 四、「整页一次弹出」到底违反了几条

我上一版 170 秒的问题，材料里其实早有明文：

```
违反 V1  关键词卡整页同时出现，不跟口播顺序（最严重）
违反 V2  没有入场时间差，没有读完时间
违反 V3  80% 页面是纯文字，没有图形/结构
违反 V9  位移几乎全是 linear
违反 Q1  未做"字能不能读完"检查（长句被截断过一次）
```

**结论：不是材料没写，是我没把材料变成检查。** 这次每条都配判据，返工后逐条打勾。
