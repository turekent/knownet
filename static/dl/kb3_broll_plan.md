## 一、选段清单（4 段 + 1 段可选）

> 口径：只选**值得用形象演**的地方（抽象关系 / 情绪转折 / 看不见的机制）；
> 逐句配图一律不选 ✗。每段给：原文锚点 / 为什么值得演 / 一句话事件 / 落点时长。

### 段 1 ·「收藏了一堆，全忘了」
- **原文锚点**：「先找教程。然后收藏。然后找几篇文章。再找几个视频。看着看着觉得：'这个东西我好像懂了。'然后过两天……忘了。」
- **为什么值得演**：这是全片第一个**共鸣点** —— 所有学习者都干过。讲出来平淡，**演出来扎心**。
- **一句话事件**：**满怀期待地往桌上摞教程/文章/视频 → 越摞越高 → 一阵风（或落灰）→ 全塌成灰**
- **建议时长**：6 秒｜**落点**：「然后过两天……忘了」这句的「**忘了**」出口时画面塌掉（偏晚 0.2–0.5s）

### 段 2 ·「关掉文章，我马上卡住」
- **原文锚点**：「但是如果现在让我关掉文章，自己讲三分钟……我可能马上就卡住。」
- **为什么值得演**：**"看懂了"和"讲得出"之间那道墙** —— 这是全片的核心命题，光讲没有体感。
- **一句话事件**：**IP 自信地站起来要讲 → 张了张嘴 → 一堆词卡在半空 → 僵住**
- **建议时长**：5 秒｜**落点**：「**卡住**」二字

### 段 3 ·「他把道法跟火影拼在一起」
- **原文锚点**：「他拿道法跟火影拼在一起，估计也就他一个人看得懂。但是他能记住。」
- **为什么值得演**：全片唯一的**温度**。抽象道理需要一个孩子来落地。
- **一句话事件**：**一本正经的课本 → 两页被拼到一起（火影的画风贴上去）→ 歪歪扭扭但合上了 → IP 点头**
- **建议时长**：6 秒｜**落点**：「**但是他能记住**」前半拍
- **注意**：**不出现任何真实动漫 IP 形象** ✗ —— 只用"格子/剪影/符号"暗示"拼在一起"，避免版权 ✗

### 段 4 ·「两条路径：以前 vs 现在」
- **原文锚点**：「以前是：我 → 看资料 → 觉得懂了。现在是：我 → 学一点 → 讲出来 → AI 挑错 → 再理解 → 再讲 → 再验证。」
- **为什么值得演**：这是**方法论本身**，必须一眼看懂。
- **一句话事件**：**上面一条直线（很短，走到一半断了）→ 下面一条循环回路（转两圈亮起来）**
- **建议时长**：7 秒｜**落点**：「**再验证**」出口时回路闭合亮起

### 段 5（可选）·「看懂 / 会用 / 掌握 三层隔着」
- **原文锚点**：「原来'看懂'和'会用'，中间隔着很远。而'会用'和'真正掌握'，中间又隔着一层。」
- **一句话事件**：**三个平台，中间两道深沟 → IP 站在第一层，往前看**
- **建议时长**：5 秒｜**落点**：「**又隔着一层**」

### 明确不演的（及原因）
| 不演 | 原因 |
|---|---|
| 25–35 秒**真实对话录屏** | 这段要**真人真对话**，演出来是假的 ✗ 直接放录屏 ✓ |
| 「我以前以为…是我的顺序错了」等过渡句 | 交代性内容，演了反而拖节奏 ✗ |
| 结尾 CTA 与系列签名 | 固定件，按系列统一补 ✓ |
| 「看十篇不如自己讲一遍」这类总结句 | 属于**收束**，用字卡/落版即可 ✓ |

**总时长**：约 **24–29 秒**（4 段）；加可选段共约 34 秒。占全片约 15–20% ✓（不抢真人主镜）。

## 二、IP 角色设定卡（文字版 · 待用户挑方向）

### 真人基底（从用户照片提取，**只用他本人照片** ✓）
| 项 | 描述 |
|---|---|
| 年龄段 | 46 岁中年男性 |
| 脸型/气质 | 方圆脸，眉骨略平，笑起来眼尾有明显纹路；**沉稳、不锋利** |
| 发型 | 短寸/短发，发际线略后，鬓角短 |
| 体型 | 中等偏壮，肩不塌、腰背直（**不许画胖 ✗**） |
| 常见着装 | 深蓝 polo / 白衬衫 / 深灰外套；**无领带、无西装三件套** ✗ |
| 常态表情 | 平静偏笑，说话时眉心微动 |
| 标志动作 | 竖大拇指、手握钢笔沉思、双手插兜站定 |

### 三个形象化方向（**用户挑一个** ✓）
**方向 A · 写实偏卡通（推荐 ✓✓）**
- 像他本人 **80%**：五官、发型、体型都保留，只做轻风格化
- 好处：**观众一眼认得出是他** ✓ 口播系列最需要这个 ✓
- 风险：AI 生成时容易"美化过头" ✗ → 必须锁"不许瘦脸/不许磨皮"

**方向 B · 布偶化（亲和 ✓ 动作夸张 ✓）**
- 深海蓝布偶（品牌色 #1E3A5F），保留他的发型轮廓与眉眼；**不拟物化、不动物化** ✗
- 好处：**情绪与动作可以夸张** ✓（被吓一跳、卡住、翻书 ✓）
- 风险：辨识度下降 ✗ → 靠发型 + 眉眼 + 常穿深蓝来认人 ✓

**方向 C · 简笔线稿（最便宜 ✓ 信息图最配 ✓）**
- 单一深蓝线条 + 白底 + 一处实心色块
- 好处：出图快、风格统一、和字卡/图表天生搭 ✓
- 风险：表情有限 ✗ → 适合段 1/4/5，不适合段 3（温度不够）

### 不论哪个方向，都必须写进角色卡的**禁止项** ✗
1 不许换发型 / 换体型 / 改年龄段
2 不许加眼镜（**除用户确认**）
3 不许改肤色、不许磨皮瘦脸
4 不许出现乱码、假字、logo、平台 UI
5 不许用第三方 IP 形象或他人肖像

### 出图/出片硬约束
- 多角度（正 / 侧 / 四分之三）+ 表情（平静 / 疑问 / 笑意）+ 动作（站立 / 持物）+ **干净全身**
- 每个 B-roll 段落**画风一致** ✓ 相邻段**换构图不换画风** ✓（表一）
- 段 3 不得出现真实动漫形象 ✗（用格子/剪影暗示 ✓）
