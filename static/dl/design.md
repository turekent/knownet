## 1. 画幅与节奏（冻结）

| 项 | 值 |
|---|---|
| 画布 | **1280×720 / 16:9 / 30fps** |
| 目标时长 | **145–155s**（含片尾三张卡 9.5s） |
| 真人画面占比 | **≥50%** |
| 暗色底占比 | **≤40%**（一半以上用暖白卡） |
| 非字幕视觉变化 | **每 ≥10 秒一次**，最长空档 ≤12s |

---

## 2. 背景 = 三层（不是一张图）

| 层 | 是什么 | 参数 |
|---|---|---|
| **L1 静图** | 每 **5 秒**一张（155s ≈ 30 张） | 1440×720 出图，裁掉底部 60px「AI生成」水印 |
| **L2 动画层** | 每张静图拆 **2 个机位**缓慢运镜 + 硬切 | 机位 A：zoom 1.00→1.14 缓推；机位 B：从 1.30 起换方向；景别差 ≥1.5× |
| **L3 动效文字** | 大字/数字滑入·弹入·上浮，透明 PNG 序列 | 按句入场，out_i = enter_{i+1} − 0.15 |

**缺 L2 → 像静态图；缺 L3 → 只有底图没有信息层级。三层齐了才算「背景」。**

规则：
- 背景图**每部片子新出**，不复用旧库（交付前用 md5 比对旧库，重复数必须为 0）
- 背景里**不许有第二个清晰人脸**（同性别同年龄会被看成两个人在讲话）
- 出图提示词只写「有字必须准」，**不写「禁止一切文字」**（用户已纠正）

---

## 2.5 七类页面（丰富度来自页面种类，不是特效）

每 **4–6 秒**一页轮换；**三项恒定不动**：底部字幕位置、人像小窗位置、配色与大字系统。

| # | 页面 | 用在本文哪一段 |
|---|---|---|
| ① | 口播 + 大字 | A1 钩子、D 顿悟、H、I、J、K |
| ② | 卡片页 + 真人小窗 | G 方法卡、片尾三张卡 |
| ③ | 全屏原文 / 提示词 | 可抄提示词卡 |
| ④ | 列表 · 数据卡 | C 九问卡 |
| ⑤ | 全屏 AI 素材 | B 案例段的情绪补充（可选） |
| ⑥ | 全屏实拍 B-roll | 无（本篇无素材，不硬做） |
| ⑦ | 结尾互动卡 | L 后品牌卡 |

**硬约束**：卡片页上真人**缩成小窗持续存在**，不许整页消失（观众会丢人）。

## 2.6 元素类型（页面里的零件）

### ① 真人画面（≥50%）
- 从 **1920×1080 原片**取，先 `crop=1920:880:0:0` 去烧制字幕
- 人物占画宽 **1/3–1/2**；关键句推近 **5–8%**
- 肤色自然不磨皮；保留手势
- 底部字幕：44px 白字 + 3px `#0A0A0A` 描边，底距 **32px**，最多 2 行

### ② 暖白解释卡（E1 / E2 / F / G 前半）
- 卡片底 `#F5F7FA`，占画宽 **62%**，靠左，x 从 **70px** 起
- 标题 `#1E3A5F` **52–56px / 900**
- 正文 `#1A1A24` **32px / 500**
- 橙色 `#E06000` 只标关键词，**每张最多 2 处**
- 单张停留 **3–5s**；卡片右侧留出人像位（x>800）

### ③ 案例对话框（B / C 段）
- 左"用户"灰底气泡 `#EDEFF3`，右"AI"深蓝气泡 `#1E3A5F`
- 逐条出现（每条 2–3s，`rise` 入场，位移 24px + 透明度 0→1）
- **只用母版里真实说过的话**，不许编对话

### ④ 大字 / 金句卡（开场、D、K、片尾）
- 开场两行：`不是 AI 不行` / `是你没想清楚！`（"没想清楚"用 `#E06000`）
- 金句 76px/900，单独占屏，停留 ≤3s
- 全部**真字渲染**，禁止 AI 生成中文

---

## 3. 字幕三级

| 级别 | 用法 | 规格 |
|---|---|---|
| 一级 | 金句、核心判断 | 76px / 900，单独占屏 ≤3s |
| 二级 | 方法步骤、关键词 | 52–56px / 900，可加橙色块 |
| 三级 | 普通口播 | 44px 白字，8 向 `#0A0A0A` 描边 ±3px，底距 32px |

**左上/背景只放关键词与结论；底部字幕是口播原话，一字不改。**
**禁止两者说同一句。**

---

## 4. 人像圆窗（只在需要"人在角落"的版式里用）

| 项 | 值 |
|---|---|
| 圆心 | **(1090, 570)**，半径 **150** |
| 头部 | 头顶 **露出圆外约 50px** |
| 肩膀 | 在圆内，被圆弧自然裁切 |
| 圆盘 | 白墙贴片 `#C5C9CE`，无描边 / 无白边 / 无红框 |
| 遮罩 | 圆 ∪ 下巴以上，羽化 1.2px |
| 字幕安全区 | x 60–790，y 596–720；人像不得进入，间距 ≥24px |

> 框与描边只能留一个。若背景是纯色或与人物同色，**不画框**。

---

## 5. 片尾三张卡（顺序不能变）

1. **五步方法卡**（4s，真字）
   标题：`借鉴苏格拉底式追问的 AI 需求澄清法`
   ① 目标：我最终想实现什么？
   ② 问题：我真正需要解决的是什么？
   ③ 现状：我有什么条件、资源和限制？
   ④ 标准：什么样的结果才算成功？
   ⑤ 确认：你先复述需求、指出还缺什么，等我确认后再执行

2. **可抄提示词卡**（3s，真字，能截图）
   `先不要给我答案。请通过提问，帮我弄清楚：真正要解决的问题、目标、限制条件、成功标准。等我确认后你再执行。`
   小字：`下次用 AI，先别急着让它干活。`

3. **品牌卡**（2.5s）
   `负重进化论` ＋ 小字 `想不通的事，评论区告诉我`
   全片只出现一次 `46 岁，AI 让我重新发现自己`（文字形式，不补录）

## 6. 配色（只有这五个颜色）

```
暖白   #F5F7FA   卡片底
深灰   #1A1A24   正文
橙色   #E06000   关键词 / 强调（每屏 ≤2 处）
纯白   #FFFFFF   字幕
```

---

## 7. 禁止事项

1. 不许自编例句、自编对话
2. 不许用 AI 生成的中文字
3. 不许整条只用一个版式
4. 不许片尾写"关注我，我们一起变强"
5. 不许左上标题与底部字幕说同一句
6. 不许人物被拉扁（`scale.x == scale.y`，偏差 ≤0.1%）

## 8. 试镜（下一步，只出 3 张静帧）

**一张只验一个方向（IP 打造 p11-12）；每张附三条回源信息（Knowledge Loop p12）。**

| 帧 | 取哪一段 | 只验这一件事 | 回源句号 |
|---|---|---|---|
| S1 标题镜 | 开场 0–4s | 大字两行 + 橙字 + 人像位置，3 秒内能不能抓住 | seg 2 |
| S2 信息图镜 | C 段九问卡 | 卡片密度与逐条可读性，且不压人像 | seg 7–9 |
| S3 人物镜 | D 段顿悟 | 真人取景/推近/字幕不重叠 | seg 16–17 |

**评审三问（导演是我 03 p283、Knowledge Loop p12 合并）**
1. 三张像不像同一部片子？
2. 每张的视觉焦点是否一眼清楚？
3. 不看内容，能否认出是同一套风格？
4. （回源）这张对应哪句原话？证据是什么？在什么条件下成立？

**两问答否 → 回本文件改规则，不许逐张修图。每轮只改 1–3 个变量。**
**没有实际静帧之前，只能说「规则草案完成」，不许说「设计已验证」。**

## 9. 最小闭环（Knowledge Loop p02）

**不铺全片。先用 0–7s（A1 钩子 + 进 B 段第一张案例卡）跑通整条链**：
```
真原片取人像 → 圆窗合成 → 三层背景 → 动效文字 → 字幕 → 编码
```
跑通且自检全绿，再扩到 155s。
