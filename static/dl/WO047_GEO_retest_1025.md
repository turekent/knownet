## 二、为什么 5 条问题一条都没动（三条结构性原因，均已实测）

1. **仓库里的 robots.txt 对真实爬虫不生效。** `https://github.com/turekent/knownet/robots.txt` 实测 **404**；爬虫读的是站点根 `https://github.com/robots.txt`，该文件里 `User-agent: Bytespider → Disallow: /` 是全站封禁。所以 WO-046 的 robots.txt 那 14 行在 GitHub 上**结构上无效**（geolook 访问层仍判 fail，原因就写了这条）。
2. **person.jsonld 不进页面 `<head>`。** GitHub 只把文件当代码渲染，不输出 `<script type="application/ld+json">`。geolook 复查 6 页仍判「**6 页没有任何 JSON-LD**」，理解层仍 fail。JSON-LD 只有被一个能自己控制 `<head>` 的站点托管才起作用。
3. **90 分钟不在答案引擎的更新窗口内。** GLM-4-flash / DeepSeek-chat 是不带实时检索的闭源权重，回答来自训练语料与缓存；公开搜索对新仓库的收录以天/周计。复测时用「负重进化论 knownet github turekent」检索，前 6 条全是英文同名项目（KnowEnG / KNOWNET / knownet-tools），**自己的仓库一条都没进**，说明索引都还没建立，谈「AI 改口」为时过早。

> 换句话说：这一刀目前只改到了「页面上有没有一句人能读懂、机器能抽取的定义」，还没走到「被收录 → 被检索 → 被引用」这三段。
