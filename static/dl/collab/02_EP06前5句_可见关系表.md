# EP06 前 5 句 · 可见关系表

> 依据：`semantic-planning.md`「每个语义单元先回答画面补充了哪种可见关系」
> 五选一：人物与发言 / 比较双方 / 数量变化 / 选择的代价 / 情绪意象
> 原则：**换标题、重复原话、背景漂浮都不能代替这个关系**

---

## 第 1 句 · 0.08–4.64
**口播**：以前我学新东西的时候，基本上就是一个固定的套路

| 项 | 内容 |
|---|---|
| **可见关系** | **数量变化 + 比较**（同一个动作，产出永远相同） |
| **主重音** | "固定的套路" → **产出完全相同** |
| **解释信息** | "学新东西"这个动作 → 用**真实收藏动作**承载 |
| **物体** | 浏览器收藏夹 / 收藏星标（**真实 UI 控件**，不是色块卡） |
| **动作** | 收藏同一个东西三次，收藏夹里出现三条**标题完全相同**的条目 |
| **结果** | 三条并排，**一模一样** → 观众自己得出"套路固定" |
| **观众应看见** | 不是"东西变多"，是**变多但全一样** |

## 第 2 句 · 4.64–9.00
**口播**：找教程 收藏 再找几篇文章 几个视频

| 项 | 内容 |
|---|---|
| **可见关系** | **数量变化**（三类东西分别累积） |
| **主重音** | "收藏" —— 动作落点是**收藏夹在涨** |
| **解释信息** | 教程 / 文章 / 视频是三个**不同类别** |
| **物体** | 三个不同形态：书本图（教程）、长条文（文章）、播放框（视频） |
| **动作** | 三类依次落入同一个收藏夹，条目计数 3→5→8 |
| **结果** | 收藏夹满，但**分类标签是乱的**（都是"未分类"） |
| **观众应看见** | 收集量在涨，**但没有结构** |

---

## 第 3 句 · 9.00–11.92
**口播**：看一下就觉得这个东西我懂了

| 项 | 内容 |
|---|---|
| **可见关系** | **比较双方**（"觉得懂" vs "实际没消化"） |
| **主重音** | "觉得" —— 主观感受，不是事实 |
| **解释信息** | 他只看了**列表标题**，没打开任何一条 |
| **物体** | 收藏夹列表 + 一个"已读"勾 |
| **动作** | 鼠标从第 1 条快速划到第 8 条，**一条都没点开**，然后打勾 |
| **结果** | 8 条全部标"已读"，**展开条数 = 0** |
| **观众应看见** | 勾是打上了，**但没有任何一条被打开过** |

---

## 第 4 句 · 11.92–15.00
**口播**：其实过几天以后就会发现自己已经忘了

| 项 | 内容 |
|---|---|
| **可见关系** | **时间导致状态变化**（东西还在，人空了） |
| **主重音** | "忘了" —— 不是东西没了，是**记忆没了** |
| **解释信息** | 收藏夹内容**一条没少** |
| **物体** | 同一个收藏夹（回到第 3 句的列表） |
| **动作** | 日历翻过 3 页 → 打开收藏夹 → 8 条**全都还在** |
| **结果** | 他盯着列表，**手动去搜同一句话**（说明他忘了自己收藏过） |
| **观众应看见** | **东西全在，但他不记得了** —— 这才是"忘" |

> ⚠️ 这里我原来设计成"东西消失"，是**反的**。
> 口播说的是"我忘了"，不是"内容没了"。东西还在、人忘了，反差才成立。

## 第 5 句 · 15.00–17.84
**口播**：以前我总觉得是我自己的记性不好

| 项 | 内容 |
|---|---|
| **可见关系** | **人物与发言**（自我判断） |
| **处理** | **不做画面，保留真人** |
| **理由** | 手册明确：个人态度 / 真实经历 / 需要观众相信"这是你的判断" → 保留真人口播 |
| **接法** | 从第 4 句的收藏夹列表，**接回真人**（同一台电脑的反打） |

---

## 一句话总纲

**这五句讲的是"收藏 ≠ 学会"。**

所以整段视觉的主线是：
```
收藏夹在涨（第1-2句） → 全都标记已读但没打开（第3句）
   → 几天后东西还在人却忘了（第4句） → 回到本人（第5句）
```

**主重音只有一个：收藏夹里"东西在、理解不在"。**

## 我三次失败的原因（记录）

| 版本 | 我做的 | 错在哪 |
|---|---|---|
| v5-v8 | 纸片堆成塔埋住人 | **纸堆 ≠ 收藏**，观众要先猜纸是什么 |
| s1v2 | 抽象图标循环三次 | 图标太弱，读成"多个文件夹" |
| s1v3 | 三张色块卡复制 | 色块卡没有身份，**看不出是"收藏"** |

**共同错误：用抽象几何表达抽象概念。**
手册说的是"**先找文字背后的物体、动作、关系和变化**" ——
第 1 句的物体是**收藏夹这个真实界面物件**，不是我发明的色块。
