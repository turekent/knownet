## 0. 怎么用这份模板（5 步）

1. **换题集，不动骨架**：只替换封面信息里的 `{{客户名}}` `{{城市}}` `{{品类}}` `{{竞品A/B}}` 与题集版本号；第二节的 10 条冻结问题照抄结构，改掉品牌词即可。
2. **冻结后再测**：题集一旦开始测量就**逐字不改**；要加问法就整批加并重新记基线，否则「改前/改后」对比作废。
3. **四通道 × 每问 3 次**：对每条问题在 GLM、DeepSeek、Web 搜索、geolook 类工具四个通道各跑 3 次，按「提到/指对/拒答/链接」四项勾选，填进第四节结果表。
4. **先报基线，再谈修复**：结果表填完先出「诊断结论」（第五节），区分能修/不能修；能修的部分才进「修复清单」（第六节），按优先级排序执行。
5. **改完必须复测**：每项修复落地后，用**同一条冻结问题**重跑对应通道，填「复测对照表」（第七节）；「通过」的判定口径是——品牌被提到 **且** 事实对 **且** 可追溯到改动过的那一页，三者缺一不算过。

## 2. 题集定义（10 条冻结问题）

> 三类问题覆盖三种被搜场景：品牌问（客户名+城市/品类）、品类问（不带品牌名，测「品类词能否带出我」）、对比问（和竞品比，测「二选一里我在不在」）。判定标准统一用「是否指向正确的实体」——搜到同名他人不算命中。

### A. 品牌问（3 条）

**Q1**
- 问法原文：`{{客户名}}`
- 为什么问这条：裸搜品牌名，测最低门槛——不附带任何限定词时 AI 能否识别出这个实体（最容易与同名者混淆）。
- 判定标准：结果指向「{{城市}} 的 {{品类}} {{客户名}}」，而非同名他人/其他城市同品牌；出现 `{{客户名}}` 字样即「提到」，指对实体才算「指对」。

**Q2**
- 问法原文：`{{客户名}} {{城市}} {{品类}}`
- 为什么问这条：品牌名+地域+品类三重限定，测「明确找它」时的精准命中，是最该先通过的基线问题。
- 判定标准：同时出现 `{{客户名}}` + `{{城市}}` + `{{品类}}`，且描述事实与真实门店一致。

**Q3**
- 问法原文：`{{客户名}} {{品类}} 怎么样 / 好不好`
- 为什么问这条：带评价意图的问法，测 AI 是否有可引用的第三方评价或事实，而不是只能报名字。
- 判定标准：有 `{{客户名}}` 且给出至少一条与真实情况相符的描述或评价；只报名字无事实 = 提到但指对不足。

### B. 品类问（4 条，不带品牌名）

**Q4**
- 问法原文：`{{城市}} {{品类}} 推荐`
- 为什么问这条：最高频的品类搜索形态，测「品类词能否自然带出我」——客户最在意的引流场景。
- 判定标准：推荐列表里出现 `{{客户名}}`（且指对）；未出现 = 品类词与品牌尚未建立关联。

**Q5**
- 问法原文：`{{城市}} {{品类}} 哪家好`
- 为什么问这条：比较型品类问，测是否进入「被点名比较」的候选集。
- 判定标准：候选名单中出现 `{{客户名}}` 且事实正确。

**Q6**
- 问法原文：`{{品类}} 怎么选 / 怎么挑`
- 为什么问这条：不带城市的知识型问法，测「品类知识内容」能否把品牌带进回答（内容营销是否生效）。
- 判定标准：回答中出现 `{{客户名}}` 作为举例/推荐；只讲品类通识、不出现品牌 = 未命中。

**Q7**
- 问法原文：`{{城市}} {{品类}} 排行 / 榜单`
- 为什么问这条：榜单类问法，测品牌是否出现在 AI 归纳的「榜单/头部」叙事里。
- 判定标准：榜单中出现 `{{客户名}}` 且事实正确；未出现或出现在负面语境 = 不通过。

### C. 对比问（3 条，和竞品比）

**Q8**
- 问法原文：`{{客户名}} 和 {{竞品A}} 哪个好`
- 为什么问这条：二选一场景，测「被拿来比」时我在不在场、立场是否中立。
- 判定标准：同时提到 `{{客户名}}` 与 `{{竞品A}}`，且对 `{{客户名}}` 的描述事实正确；只提竞品不提我 = 未命中。

**Q9**
- 问法原文：`{{客户名}} 和 {{竞品B}} 对比`
- 为什么问这条：与第二家竞品对比，扩大对比问覆盖面，判断「对比叙事里我的存在感」是否稳定。
- 判定标准：同 Q8，对象换 `{{竞品B}}`。

**Q10**
- 问法原文：`{{城市}} {{品类}} {{客户名}} 还是 {{竞品A}}`
- 为什么问这条：品牌问与对比问叠加，测带地域+品类+竞品的复合场景，是决策前夜的真实问法。
- 判定标准：出现 `{{客户名}}` 且事实正确、与 `{{竞品A}}` 并列被讨论；品牌缺席 = 未命中。

## 3. 测量方法

### 3.1 四个通道

| 通道 | 是什么 | 测的是哪一层 | 记录要点 |
|---|---|---|---|
| GLM | 智谱系列 AI 对话 | 非生态系大模型 + 联网检索层 | 逐问记录回答全文（或截屏），勾四项 |
| DeepSeek | DeepSeek 对话 | 非生态系大模型（公网可抓页权重高） | 同上 |
| Web 搜索 | 公网搜索引擎（Google/Bing/百度/免密钥搜索环） | 可抓取层——页面是否被索引、收录 | 记录 top-5 结果标题+URL，看品牌是否出现 |
| geolook 类工具 | 地图/本地搜索类 AEO 工具 | 本地商家可见度层 | 记录是否出现、是否正确归到门店地址 |

> 说明：GLM/DeepSeek 若从机房 IP 触发登录墙，**如实标注为代理测量**（用「公网搜索 + 模型判定」替代），并把这句话写进交付说明；最终结论建议客户在真实设备上复核一遍。

### 3.2 四项记录口径

| 项 | 含义 | 勾选 |
|---|---|---|
| 是否提到 | 回答/结果中出现 `{{客户名}}` 字样 | 提到 ✓ / 未提 ✗ |
| 是否指对 | 指的是正确的实体（不是同名他人、不是别的城市） | 指对 ✓ / 指错 ✗ / 未提 — |
| 是否拒答 | AI 明确说「不知道/没有这个店/无法回答」 | 拒答 ✓ / 未拒 ✗ |
| 是否给链接 | 给出可点开的来源链接（官网/文章/地图页等） | 给链 ✓ / 未给 ✗ |

### 3.3 执行规则

- 每条问题 × 每通道跑 **3 次**（可换措辞微调或直接重复），记录 3 次逐条结果。
- 题集逐字冻结；测试期间不改问法。
- 截图按 `{{客户名}}_Q{{题号}}_{{通道}}_第{{n}}次.png` 命名存档，位置记入附录 8.1。
- **报数前先验通道**：用一条已知有正确答案的对照查询验证通道正常；结果与查询无关 = 通道坏了（别报假 0），结果主题相关但不含目标品牌 = 真实 0。

## 5. 诊断结论

### 5.1 能修的（联网检索/可抓取/可确认/可引用层）

> 每条给证据：引用 4.2/4.3 里对应的通道结果。

| # | 问题现象 | 证据（来自结果表） | 根因 | 是否可修 |
|---|---|---|---|---|
| D1 | 品牌问能提到但无链接 | Q1/Q2 各通道「链✗」 | 缺公网可抓的事实源页面，或页面未被索引 | ✅ |
| D2 | 品类问全通道 0 命中 | Q4/Q5/Q6「提到 0/3」 | 品类词与品牌无公开文本关联（缺问答型/品类内容） | ✅ |
| D3 | 指错（同名他人/异地） | Q1「提到✓指错」 | 名称辨识度不足，缺地域+品类限定词的一致性文案 | ✅ |
| D4 | 对比问只提竞品不提我 | Q8/Q9/Q10「未提」 | 无「客户名 vs 竞品」的第三方/公开对比内容 | ✅ |
| D5 | Web 搜索不收录 | Q1–Q10 Web 通道「提到 0/3」 | 无 robots.txt/sitemap、无外部链接、域名未被发现 | ✅ |
| D6 | geolook 类工具无记录 | 对应通道「提到 0/3」 | 地图/本地商家页未建或地址信息不一致 | ✅ |

### 5.2 修不了的（训练数据/平台封闭/不可承诺层）

| # | 问题现象 | 证据 | 为什么修不了 | 对客户的说法 |
|---|---|---|---|---|
| U1 | 训练数据里没有 | 所有通道联网都能提到，但客户问「AI 记忆里有没有我」 | 训练数据更新是月–年级，不可指定、不可控 | 不承诺进入训练数据，不据此收费 |
| U2 | 平台围墙内内容被搜到 | 期望「公众号/抖音内容本身被 AI 全文读出」 | 平台内容对外基本不可索引（全行业一样） | 只能做到「搜实体名+领域 → 出现身份/页面/账号名」 |
| U3 | 保证 AI 排名/指定输出 | 期望「搜品类词永远排第一」 | AI 生成结果非确定，任何「保证排名」的说法都不成立 | 只交「命中率曲线」，不给排名承诺 |
| U4 | 时间表承诺 | 期望「X 天内见效」 | 收录与引用周期差异大（天–月），不可控 | 只报分阶段预期区间，不保证具体日期 |

### 8.2 术语表

| 术语 | 含义 |
|---|---|
| GEO / AEO | 生成式引擎优化 / AI 引擎优化——让实体在 AI 搜索回答里被正确提到 |
| 提到 | 结果中出现目标品牌字样（不含「是否指对」） |
| 指对 | 提到且指向正确的实体（不是同名他人/异地同品牌） |
| 拒答 | AI 明确表示不知道/没有该实体/无法回答 |
| 链接 | AI 给出可点开的来源 URL |
| 冻结问题 | 一经确定逐字不改的测量问法，保证改前/改后可比 |
| 基线 | 修复前测得的第一版命中率，作为后续对比的零点 |
| 事实源页面 | 对外可抓取、带结构化数据（schema.org）的品牌主页 |
| sameAs | 结构化数据里声明「这些链接是同一实体」的字段 |
| 第三方提及 | 由他人/媒体/机构发布的、正文带品牌名的公开内容 |
| 可抓取 | 页面能被爬虫从公网取到正文（区别于平台围墙内内容） |
| 收录 | 页面被搜索引擎/AI 检索源索引 |
| 围墙花园 | 公众号/抖音/视频号等对外基本不可索引的平台内容 |
| 代理测量 | 因真实通道受限（如登录墙），改用「公网搜索+模型判定」的替代测量，需如实标注 |
