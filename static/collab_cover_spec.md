# 负重进化论 · 封面模板规格（Rio 出图照这个做）

> 依据：用户提供的 4 张已发布封面 + 1 张另一系列封面，逐张实测得来。
> 目的：**以后出封面套模板就行，不用每次重新设计。**

→ 主系列画布统一 **1672×941（16:9）**；另一系列 2.34:1，**不套本模板**（见第 7 节）。

## 1. 画布与格式
- 画布 **1672×941**（16:9）
- 输出 **JPEG**（质量 92+，实测 180–270KB）；源文件另存 PNG
- 底图先出 **1920×1080**（或 2048×1152）再裁到 1672×941，留裁切余量

## 2. 固定版式（五区结构，坐标 = 占画布宽/高的百分比）

| 区 | 位置 | 内容 |
|---|---|---|
| ① 品牌 logo | 左 4–5%、上 4–5%；宽 ≈15%、高 ≈7–8% | 「负重进化论」+ 橙色笔刷下划线 |
| ② 主标题 | 左起 5%、上起 10–12%、下至 58–60%；宽 ≈42–48% | **4 行**，句式固定（第 3 节） |
| ③ 人物 | 右半幅：头心横向 60–65%、纵向 35–40%；整体高 80–90%；**面朝左**（与标题对望） | 用户真人照（抠像合成） |
| ④ AI 能力标签 | AI 芯片图标中心 ≈(78%, 36%)；右侧 4 枚标签卡**纵向阶梯**排布，单枚宽 ≈12–15%、高 ≈7–8%，间距 8–10%，带细连接线 | 写文章 / 做PPT / 写代码 / 做视频 |
| ⑤ 桌面道具 | 底部 20–25% 高 | 左=三本书（书脊 3 行字）／中=黑杯 + 纸笔／右=笔记本 |

视觉动线：① 左上 logo → ② 左侧主标题 → ③ 中右人物 → ④ 右侧标签 → ⑤ 底部桌面文字

## 3. 主标题的四行句式（换关键词即可，结构不动）
1. `46岁，` —— 数字/年龄行
2. `我发现AI不是来` —— 主陈述
3. `抢我饭碗的` —— **橙底白字**强调行
4. `——老登的春天来了` —— 手写体副标 + 黄/橙弧线

## 4. 配色（三色体系 + 一个强调色，实测聚类）
- 主深色 `#000000`–`#1A1A24`（藏青/黑：标题、衣服、道具）
- 主亮色 `#E0E0E0`–`#FFFFFF`（白：标题、标签卡文字）
- 天蓝 `#80C0E0`–`#A0C0E0`（背景天空/信息层）
- **强调橙 `#E06000`** —— 只用在四处：logo 下划线、标题强调行底色、杯子文字下划线、核心弧线
- 辅色（肤色/木色/绿植/灰蓝建筑）不计入体系

## 5. 字体
- 主标题：**Noto Sans SC 900**（与片内动效字同一套；字重不够会显得单薄）
- 强调行：同字体 + 橙底白字
- 手写副标：手写体；没有就退化成 Noto Sans SC 700 + 手工弧线
- **所有文字必须是真字**（真字体渲染）；**AI 画的字一律不用**

## 6. 文案槽位（换内容只改这几处）
| 槽位 | 样本 |
|---|---|
| 标题第 1 行 | 46岁， |
| 标题第 2–3 行 | 我发现AI不是来 / 抢我饭碗的 |
| 标题第 4 行 | ——老登的春天来了 |
| AI 四标签 | 写文章 / 做PPT / 写代码 / 做视频 |
| 书脊三行 | AI × 解决问题 / 经验 × 新能力 / 普通人的进化之路 |
| 笔记本面 | AI + 经验 = 新可能 |
| 杯子 | 负重进化论 |

## 7. 系列差异（★别搞混★）
- 本模板**只适用「负重进化论」主系列**：1672×941 / 五区结构 / 白+藏青+橙。
- **另一系列（孙宇晨 / 健身）版式不同**：实测 **1920×819（2.34:1）**、深黑+深蓝底、左右对比构图、数据界面元素 —— **不要套本模板**，按那一套的参考件单独做。

## 8. 出图三步（照做，别跳）
1. **底图**：智谱 CogView-4（尺寸只能 `1440x720`）出场景/道具；人物用**用户真人照**抠像合成；书/杯/笔记本可 AI 出或用素材
2. **文字层**：**真字体渲染**（PIL 或 HTML 都行），按第 2 节的坐标摆
3. **校对**：逐字核标题/标签/书脊/笔记本四处；有错字重做；不出现未经用户确认的 logo/品牌

## 10. 反推：底图提示词（可直接粘贴，智谱 CogView-4）

**总判断：本系列封面 = AI 底图 + 用户真人照抠像 + 真字叠层 + 矢量图标/标签**（不是一张 AI 图）。
所以只有**底图和道具**需要提示词，人物和全部文字都不许让 AI 画。

**① 场景底图（通用，机器人/日常题材用）**
```
现代中式办公室内景，落地窗外是清晨的山湖与城市天际线，阳光从山后升起照亮房间；
前景是木色办公桌，桌上有打开的银色笔记本电脑、一只黑色马克杯、三四本叠放的厚书和一盆绿植；
画面右侧约 40% 留空给人物站位，左半部保持简洁空旷；
柔和的暖色晨光从左后方打进来，冷调阴影；写实摄影风格，电影感构图，浅景深，4K，
不要出现乱码或假字，文字若出现必须清晰准确，不要出现清晰人脸
```
尺寸：`1440x720` → 裁到 1672×941

**② 马拉车底图（励志/号召题材）**
```
清晨的金色乡间道路，一辆中式木制双轮马车由三匹并排的骏马牵引向前奔跑，扬起轻微尘土；
背景是薄雾中的山野与远树，暖色逆光从正前方照来；实拍感 + 电影感构图，动势强烈，4K，
不要出现乱码或假字，不要出现清晰人脸
```

**③ 白色 AI 机器人（道具素材）**
```
一台白色圆润造型的服务机器人，屏幕脸显示微笑表情，站在现代办公室桌边；
柔和环境光，简洁背景，3D 渲染质感，产品级打光，4K
```

**④ 合成步骤（图层顺序，坐标=占宽高百分比）**
1. 底图生成 → 裁到 1672×941
2. 人物：用户真人照抠像，缩放到**高 85–90%**，量在**横向 42–88%**、**面朝左**；边缘收 1px
3. 道具文字面：**笔记本面 / 杯身 / 三本书书脊**用真字，按透视贴（PIL 或 PS 都行）
4. 图标区：AI 芯片图标 + 4 枚标签卡**矢量绘制**（圆角 + 半透明底），锚点 ≈(78%, 36%)，纵向阶梯
5. 品牌与标题：左上 logo（宽 15%）+ 左侧四行标题（第 3 行橙底白字）
6. 导出 JPEG（质量 92+）

**可复用点**：换题材只改①的「场景+窗外」，③换道具；版面坐标、配色、标题句式全不动。
**推测项（做的时候以实物为准）**：机器人那条若胸前的「AI」二字被 AI 画花，**后期用真字覆盖**；
书脊/杯身/笔记本面的字建议**一律后期真字**，不要赌 AI 画对。
