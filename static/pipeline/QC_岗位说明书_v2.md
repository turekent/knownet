## 三条铁律
1. **只认成片，不认参数** —— 从 mp4 解码测，禁止用渲染脚本常量（如 applied_crop）自证
2. **全量不抽样**（专项重测另有抽样要求时以工单为准）
3. **漏检追责** —— 用户先发现 = 检查岗 FAIL，记一次



## 总判口径（#518§二）
1. **总判只看主片**；对照片/弃用片的问题另记一条，**不参与总判**。
2. 「交付件不得带空白首帧」仍是硬规则——对照片若复出必须先修首帧再开 A9。
3. 禁止用「两片必检项均过线」作为总 PASS 条件。

## A9 人像放置稳定性（写死 · #505§五）
- **只测人像 ROI**；不测卡片/流程条/文字
- **判据：std ≤0.3px 且 max jump ≤1px**（头/中/尾各 ≥30 有效帧；输出 x/y 序列、std、max jump；FAIL 附帧号+数值+截图）
- 人像位置整片应固定；任何跳 = 缺陷（根因常见：逐帧重算 bbox）

### A9 测规四条（必须按此测，否则测值无效）
1. **掩膜**：用人像未入画的背景母版做 `absdiff` 抽人像 mask。工单未交母版时，用 `--bg` 指定背景帧/图；仍无则退到肤色或分割兜底，并在报告注明兜底路径。
2. **ROI 一次冻结**：用有效帧 mask 并集生成 ROI **一次**，整段冻结；**禁止**逐帧重算 bbox / 追肩追头。
3. **置信剔除**：相邻帧相位相关 `resp < 0.3` 的对整对剔除，不进 std/max jump；报告须**并列被剔帧号**。
4. **首帧与出入场**：片首帧、淡入/淡出与出入场过渡帧**不计入**统计。**交付件不得带空白首帧**（首帧无人/近空导致均亮差异常即不合格素材，须先修片再开 A9）。


## A7 背景换镜有变化（v2.2 · Hermes #524）
- **只测背景/镜间接缝**；不测人像
- **解码**：必须用 **OpenCV `cv2.VideoCapture` 逐帧解码**取上段末帧与下段首帧。**禁止** `ffmpeg -vsync 0 -update 1` 或按帧序列文件名排序取末帧（会抽错帧，阈值再准也废）
- **指标**（对灰度差 `d = gray(A末) - gray(B首)`）：
  - `bias = mean(d)`；`r = d - bias`（扣整体电平偏移）
  - `f5 = fraction(|r| > 5) * 100%`；`p99 = percentile(|r|, 99)`
- **判定三态**：
  - `f5 < 0.05%` → **FAIL**（同帧硬切）
  - `0.05% ≤ f5 < 0.20%` → **INCONCLUSIVE**（报 f5/p99/bias，人工看一眼）
  - `f5 ≥ 0.20%` → **PASS**（辅证 `p99 ≥ 4` 加严信心）
- **辅证人工**：两帧 std 差 >3 或肤色占比差 >0.5% 时必须人工看一眼再判
- **废弃**：旧口径「mean|Δ| < 0.5 灰度级判同帧」（二次编码电平偏移可达 ~1.48，真接缝可误杀、同帧可漏判）
- **脚本**：`seam_check.py`（与验收岗同一脚本）；反例：`--make-counter` 或已知坏片 `wo044_counter_sameframe.mp4`
- **报告**：每对接缝一行 f5/判定；必须另附 ≥1 个同帧硬切反例且判 FAIL

## A10 图形动效连续性（#491 新增 · #505 改跳帧上限 · #524 接缝单列）
- **只测图形层**（卡片、流程条、文字动效）；**不受 A9 约束**
- 三项段内：
  1. **闪帧**：相邻帧平均亮度差 ≤ 8/255
  2. **跳帧**：单帧位移 **≤ 32px**（**工程绝对上限**，非「设计值×2」推导；设计位移更大须工单另批）
  3. **回跳**：动效方向必须单调，不许反向突跳
- **接缝检项单列一行**（与段内跳帧分开报）：跨段接缝一律用 A7 v2.2 的 f5 三态；**不得**用「中帧 hash 不同」代替「接缝不是同一帧」
- 故意飞入/点亮等设计位移 **不算 A9 FAIL**

## 报告格式
固定四列：`检查项 | 实测值 | 阈值 | 结论`
有人像则必含 **A9**；有图形动效则必含 **A10**。缺行 = 报告不合格。
A9 报告另须：mask 来源（母版 / --bg / 兜底）、ROI 是否冻结、被剔帧号列表、是否剔除首帧/出入场。
