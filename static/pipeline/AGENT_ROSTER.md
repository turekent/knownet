# Rio 多 Agent 岗位名册（v1 · 2026-10-24）

> 原则：**一个岗位一个 agent，一个工单一件交付。**
> 检查岗与渲染岗必须分离；检查岗有权判 FAIL，渲染岗无权自判 PASS。

## 一、岗位表

| 岗号 | 岗位 | 只做什么 | 只交什么 | 权限 | 禁止 |
|---|---|---|---|---|---|
| **QC** | 检查岗 | 独立验收成片 | `QC_REPORT.md`（四列：检查项｜实测值｜阈值｜结论） | **可判 FAIL** | 不许改片；不许用渲染参数自证 |
| **RND** | 渲染岗 | 出片（HyperFrames） | `*.mp4` + 3帧 + sha16 + summary(8字段) | 无 | 不许自判 PASS；不许交未过 A9 的片 |
| **TOOL** | 工具评估岗 | 装工具、验通路 | 接入说明（≤30行）+ 1 个样片 | 无 | 不许改生产管线 |
| **GEO-R** | GEO 资源岗 | 搜 + 读 + 四行摘要 | 资源清单（≥15 条） | 无 | 此阶段不许装工具、不许写码 |
| **GEO-M** | GEO 方法岗 | 合并去重成手册 | 操作手册（五章） | 无 | 不许引入未验证方法 |
| **GEO-E** | GEO 测量岗 | 跑基线测量 | 题集表 + 前后对比 | 无 | 不许改冻结题集 |
| **CARD** | 卡片岗 | 出知识卡 | 卡片 md（可复用/有判断/有出处） | 无 | 不许写无出处卡 |
| **RPT** | 研报岗 | 每日研报 HTML | 单文件 HTML | 无 | 不许带密钥 |

## 二、工单流转

```
我（Hermes）发工单 → 对应岗位接单 → 到点交付 → 交 QC 核（若是片）
                     ↓                              ↓
                  逾期记「未交」              PASS→我报用户 / FAIL→退回 RND
```

**硬规则**
1 一条消息**只装一个工单**，工单号写在首行，例：`【→gork】工单 WO-024 | QC`
2 回报**只报工单号 + 结论 + 数字**，不写过程
3 逾期不解释，直接记「未交」，我按台账推进
4 同一岗位同时只开一个工单，避免并行打架
