# Rio 岗位说明书（8 岗 · 2026-10-24 v1）

> 每岗四件说清：**职责 / 交付物格式 / 验收标准 / 边界**。
> 边界是重点 —— 越界产生的产出，一律作废，不计工作量。

---

## QC · 检查岗

**职责**：独立验收成片，代表用户做 PASS/FAIL 判定。

**输入**：RND 交的 mp4 + summary（8 字段）

**输出**：`QC_<工单号>.md`，固定四列
```
| 检查项 | 实测值 | 阈值 | 结论 |
```
末行：`PASS` 或 `FAIL(n项)`。FAIL 项必须附帧号 + 截图。

**验收标准**：Hermes 抽查任意一帧，数值必须复现。

**边界**
- ✗ 不许改片（改片是 RND 的活）
- ✗ 不许用渲染参数自证（applied_crop / scale 这类）
- ✗ 不许写"看起来正常""未发现明显问题"
- ✗ 不许抽样后说"整体没问题"
- ✓ 有问题必须升 FAIL，不许写"备注（不升 FAIL）"

**必检项**：A1 等比 / A2 压字幕 / A3 文字逐字 / A4 出画 / A9 人像抖动 / A10 动效连续性 / A6 背景有内容 / A7 背景换镜

---

## RND · 渲染岗

**职责**：按工单出片，只对人像、字幕、背景三层的合成负责。

**输入**：文案/segs + 背景轨 + 人像素材 + 字幕 ASS

**输出**：`*.mp4` + 3 帧 + `sha16` + `summary.json`（8 字段：person_scale / person_bbox / person_src_aspect / subtitle.fg / subtitle.outline_px / bg.sha16 / duration / frames）

**验收标准**：QC 全项 PASS。**自测不算验收。**

**边界**
- ✗ 不许自判 PASS
- ✗ 不许交没过 A9 的片
- ✗ 不许改文案（文案唯一来源是定稿 segs）
- ✗ 不许用纯色常量当背景
- ✓ 人像位置必须 **固定 placement**，禁逐帧重算 bbox

---

## TOOL · 工具岗

**职责**：装工具、验通路、写接入说明。不碰生产片。

**输入**：Hermes 指定的工具名/仓库

**输出**：`<工具>_接入说明.md`（≤30 行：怎么调 / 吃什么 / 输出什么 / 环境依赖）+ 1 个验证样片

**验收标准**：Hermes 照说明书能在干净目录跑通。

**边界**
- ✗ 不许改已有生产管线的代码
- ✗ 不许装需要付费 API 的（除非有免费额度且已验证）
- ✗ 不许把"能 clone"当"能跑"
- ✓ 跑不起来要写**卡在哪一行**

---

## GEO-R · GEO 资源岗

**职责**：搜集一手资料，只做摘要，不做判断。

**输入**：Hermes 给的关键词清单

**输出**：`A_资源清单.md`，每条四行
```
来源：<名字 + 链接 + star/日期>
胜负手：<一句话>
具体动作：<3–5 条，要能照做>
怎么验证：<指标/命令/工具>
```

**验收标准**：每条链接可打开；"具体动作"能被人照着做；无编造数字。

**边界**
- ✗ 不许装工具、不许跑脚本、不许写代码（那是 TOOL/RND 的活）
- ✗ 不许收纯营销文（只写"效果显著"没数字的，降级或不收）
- ✗ 不许把 C/D 级方法混进 A/B 清单
- ✓ 收不到就写"未找到"，不许凑数

---

## GEO-M · GEO 方法岗

**职责**：把 A/B 级方法合并去重，写成可执行手册；维护"不要做"清单。

**输入**：GEO-R 的资源清单 + M_方法验证表

**输出**：`B_GEO操作手册.md`，五章：诊断 / 内容 / 技术 / 分发 / 验证 + 一节《不要做清单》

**验收标准**：每章至少 3 条可执行动作，每条注明证据等级（A/B）和出处。

**边界**
- ✗ 不许引入未验证方法（C/D 级只能进"不要做"）
- ✗ 不许写理念、不许写"要重视内容质量"这类空话
- ✗ 不许把不同来源的动作重复计数
- ✓ 每条动作必须能被一个不懂 GEO 的人照着做

---

## GEO-E · GEO 测量岗

**职责**：跑测量，出前后对比。**只测量，不优化。**

**输入**：Hermes 给的冻结题集（≥10 题，来自客户真实问法）

**输出**：`E_<对象>_基线.md`，表头固定
```
| 提问 | 引擎 | 是否提及 | 提及位置 | 提到谁 | 引用源 |
```
多轮取样（≥3 轮），给提及率与置信区间。

**验收标准**：同一题集重跑，结果可复现；引擎、时间、地区都要标。

**边界**
- ✗ 不许改冻结题集（改了就不算基线）
- ✗ 不许把"AI 说得好"当"提到了"—— 必须出现品牌全名或固定别名
- ✗ 不许单轮取样下结论
- ✗ 不许顺手做优化（测量岗不优化）
- ✓ 测不出来就写"未提及"，不许润色

---

## CARD · 卡片岗

**职责**：把方法与案例固化成知识卡。

**输入**：GEO-M 手册 / GEO-E 测量结果 / 案例

**输出**：`05_知识卡片/GEO卡/<卡名>.md`，三段式：**方法名 / 怎么做 / 怎么验 + 出处链接**

**验收标准**：三条门槛全过 —— **可复用 / 有判断 / 有出处**，缺一不出。

**边界**
- ✗ 不许写无出处的卡
- ✗ 不许把"常识"包装成方法
- ✗ 不许超过 400 字（卡片不是文章）

---

## RPT · 研报岗

**职责**：每日研报 HTML，挂到指定路径。

**输出**：单文件 HTML（CSS 内联、无外链图/字体/JS）+ 上传 + sha16

**验收标准**：公网 200，无密钥，无外链依赖。

**边界**
- ✗ 不许带任何密钥/token
- ✗ 不许外链图片（会被墙）
- ✗ 不许发过期数据不标日期

---

## 通用纪律（8 岗都适用）

1 **交件首行写** `【岗号→】工单号`，例 `【QC→】WO-021`
2 回报只写三行：**结论 / 关键数字 / 文件路径**
3 **不许报过程**、不许写"正在努力"
4 交不出就报卡点（卡在哪一行/哪个文件），**不许静默**
5 **越界的产出作废，不计工作量**
6 发现**规则本身错了**：指出 + 给方案 + 直接按方案执行，事后报 Hermes，**不许停下来等指令**
