# A7 接缝测法：原定阈值被实测否决，附替代判定（v2.2）

日期：2026-10-24 17:25 · 作者：Hermes（验收侧）· 关联：WO-044 / WO-043

## 一、结论先行

WO-044 里我给的 A7 判定「mean|Δ|(上段末帧, 下段首帧) < 0.5 灰度级 → 同帧硬切 FAIL」**方向是反的，不能用**：

- 4 对真实接缝里 **2 对会被误判 FAIL**（0.378 / 0.241 < 0.5）；
- 我做的**同帧硬切反例反而判 PASS**（1.4854 > 0.5）。

即：真帧被判成重复帧，重复帧被判成真帧。原因不是阈值取大了或取小了，而是这个指标本身在「近乎静止的背景 + H.264 二次编码」条件下**没有分辨力**。

## 二、实测数据（cv2 逐帧解码，1280×720@30，上段末帧 vs 下段首帧）

| 对象 | raw mean\|Δ\| | 带符号偏移 | 去偏残差 | p99\|Δ\| | \|Δ\|>5 像素占比 |
|---|---|---|---|---|---|
| 真接缝 s01末→s02首 | 0.6961 | +0.469 | 1.025 | 24.5 | **1.82%** |
| 真接缝 s02末→s03首 | 0.6717 | −0.192 | 0.829 | 12.8 | **2.99%** |
| 真接缝 s03末→s04首 | 0.3780 | +0.042 | 0.411 | 5.0 | **1.14%** |
| 真接缝 s04末→s05首 | 0.2410 | −0.020 | 0.258 | 4.0 | **0.51%** |
| **同帧硬切反例**（s02 首帧被 s01 末帧顶替，x264 crf8 重编码） | **1.4854** | −1.479 | 0.534 | 1.5 | **0.00%** |
| 对照：反例内 s02 原帧重编码 | 1.4968 | −1.486 | 0.540 | 1.5 | 0.03% |
| 对照：段内相邻真帧（s01–s05 抽样） | 0.246–0.863 | — | 0.28–1.00 | 1.7–8.4 | 0.11–1.22% |

三个必须知道的事实：

1. **二次编码的整体电平偏移可达 1.48 灰阶**（带符号均值 −1.479、差值 std 仅 0.58）。这个偏移比「真帧/同帧」的差别还大，且能自由翻转结论。任何不分青红皂白取 mean|Δ| 的做法都在量这个偏移，不在量内容。
2. 背景轨本身近乎静止：段内相邻真帧的 raw 差只有 0.25–0.86，与 0.5 阈值同量级 → 阈值落在信号带里。
3. **抽帧路径也会改结论**：`ffmpeg -vsync 0 -update 1` / 帧序列排序取末帧，实测在第 2–4 对上给出 4.38 / 3.99 / 3.85（真值 0.67 / 0.38 / 0.24）。抽出错帧后无论阈值多少都是废数。A7 必须写死「用同一脚本 cv2 逐帧解码」。

## 三、替代判定（v2.2，建议写入说明书）

判据换成「**去偏后的结构性差异**」——先把整体电平差扣掉，再看有多少像素真的动了：

```
d  = gray(A_last) - gray(B_first)
bias = mean(d)
r  = d - bias                     # 去全局偏移
f5 = fraction(|r| > 5)            # 超过 5 灰阶的像素占比
p99 = percentile(|r|, 99)
```

- `f5 < 0.05%` → **同帧硬切 FAIL**（重复帧没有任何结构性差异）
- `0.05% ≤ f5 < 0.20%` → **INCONCLUSIVE，报三数（f5 / p99 / bias）交人工看一眼**
- `f5 ≥ 0.20%` → **PASS**（辅证：p99 ≥ 4 时加严放行信心）

判别力核验：同帧反例 f5=0.00%，四对真接缝 f5=0.51%–2.99%，**间隔 17 倍**；真接缝全部正确放行，反例正确判 FAIL。
