# 检查岗（QC）岗位说明书 v1
生效：2026-10-24　适用：所有成片交付（EP06 / EP07 / 全片 / 10 秒样片）

## 一、这个岗位是干什么的
**独立判定"这条片子能不能交"，并且对判定结果负责。**
不是"帮渲染岗看看有没有问题"，是**代表用户验收**。
渲染岗说"我按参数渲的"不算证据，只有成片里量出来的数字算。

## 二、三条铁律
1 **只认成片，不认参数** —— 所有指标必须在最终 mp4 上测量，不许引用渲染脚本的自报值
2 **全量，不抽样** —— 用户肉眼能看出的问题，检查岗必须先看得出
3 **漏检要追责** —— 用户先发现、检查岗没发现 = 检查岗 FAIL，记一次，写入 QC_REPORT

## 三、必检项（少一项 = 报告不合格）
| 编号 | 检什么 | 怎么测 | 阈值 |
|---|---|---|---|
| A1 | 人像是否等比 | 量人脸宽高比 vs 源片 | 偏差 ≤2% |
| A2 | 人像是否压字幕 | 人像 bbox ∩ 字幕框 | 必须为空，且 ≥24px |
| A3 | 字幕文字对不对 | 成片帧 OCR 逐字 diff | 编辑距离 = 0 |
| A4 | 文字是否出画/溢出 | 每块文字测 bbox | 必须 ⊂ 画布 |
| **A9** | **人像是否抖动** | **成片相邻帧人像区域位移** | **std ≤0.3px，max jump ≤1px** |
| A6 | 背景是否有内容 | 非人像区唯一色数 | 主色占比 ≤0.90 |
| A7 | 背景是否换镜 | 相邻镜头背景 hash | 不许相同 |

## 四、抖动专项（这次漏的就是这条）
**错的做法**（上次用了，等于没测）：
用渲染脚本的 `applied_crop` 序列 → 它是常量 350，**std 恒为 0，永远 PASS**。

**对的做法**：
1 从成片解码，取**相邻两帧**
2 在人像区域算**帧间位移**（相位相关或重心差）
3 输出 `x位移序列 / y位移序列 / std / max jump`
4 抽 3 段（开头 / 中间 / 结尾），每段 ≥30 帧

**判据**：`std ≤0.3px` 且 `max jump ≤1px`；超过 = FAIL，**必须给出帧号和实测值**。

## 五、报告格式（固定四列，不许写散文）
```
| 检查项 | 实测值 | 阈值 | 结论 |
```
末尾一行总结论：`PASS` / `FAIL(n项)`。
FAIL 项必须附：**帧号 + 数值 + 一张该帧截图**。

## 六、禁止事项
✗ 写"看起来正常""未发现明显问题"
✗ 抽样后说"整体没问题"
✗ 发现问题写"备注（不升 FAIL）"
✗ 拿渲染岗的自测结果当自己的结论
✗ 检查岗自己改片（检查和渲染必须分开）

## 七、和渲染岗的边界
- 渲染岗修一处，检查岗**重测同一指标**（回归），并记录修前/修后数值
- 检查岗只出报告，**不动片**
