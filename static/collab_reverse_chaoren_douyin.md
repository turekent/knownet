# 反推：抖音「超人爸爸爱学习 · 第4集」为什么形式丰富

> 样本：https://v.douyin.com/UZCId6hBh0c/ （2026-10-10 发布，第 4 集，作者声明"内容由 AI 生成"）
> 实测规格：**1280×720 / 30fps / 61.23s**；字幕在 y≈670–700（底部 3–7%）；章节 00:00 / 00:08 / 00:23 / 00:34 / 00:45
> 方法：按章节 + 每 4 秒抽帧，16 格接触表逐格判形式（skill: prompt-reverse-engineering）

## 一、总判断：他不是"一条口播片"，是 **15 个页面**排出来的

61 秒 = **约 15 个页面，平均每 4 秒换一次版式**。口播只是其中**一种**页面。
全片只有三样东西是**恒定**的（这是"换来换去不乱"的原因）：
1. **底部字幕条**（位置/样式始终不变，y≈670–700）
2. **画中画小窗**（真人抠像，常在右上角；出现在多张卡片页上）
3. **配色与大字系统**（红/黄大字关键词、白底卡、同一套字体）

→ **变量放在"页面"，常量放在"包装"**。这是整件事的关键。

## 二、页面类型清单（7 种，可直接照抄）

| # | 页面类型 | 片中的样子 | 怎么实现 |
|---|---|---|---|
| ① | **口播页** | 真人半身 + 红/黄大字关键词 | 真人素材 + 动效文字层（大字） |
| ② | **口播 + 画中画** | 全屏卡片当主角，真人缩成右上小窗 | 真字渲染的卡片 + 抠像小窗（小窗跨多页持续存在） |
| ③ | **全屏文档/表单页** | 提示词原文、孩子的信息表单、模板 | **真字渲染**（HTML→PNG 或 PIL），不是 AI 画 |
| ④ | **列表/数据卡** | "优选书单 5 套绘本"、共读建议卡（内容切换） | 白底卡 + 图标 + 真字 |
| ⑤ | **全屏 AI 素材页** | 桌上黑色毛球插画角色 + 绘本封面 | AI 图 + 轻微运镜（静图+zoompan 就够） |
| ⑥ | **全屏实拍 B-roll** | 孩子书架前看书、父子沙发共读 | 实拍素材；可再叠一张卡 |
| ⑦ | **结尾互动卡** | 头像合成 + 爱心/灯泡/礼花贴纸 + 点赞关注评论 | 固定模板，每集复用 |

片中顺序（16 格实测）：①01 → ②04 → ①08 → ④12 → ③16 → ⑤20 → ①24 → ⑥28 → ⑥32 → ④36 → ④40 → ①44 → ③48 → ③52 → ①56 → ⑦60
→ **口播 ~5 页打底，其余 10 页全是"证据页/场景页/包装页"**。

## 三、制作链反推

| 层 | 判断依据 | 结论 |
|---|---|---|
| 真人 | 边缘有抠像痕、与小窗边框整齐 | 出镜拍摄 + **抠像做画中画** |
| 文字/界面/表单/书单 | 中文**逐字可读**、排版整齐、标点正确 | **真字渲染**（AI 画不出这种整齐） |
| 插画/毛球角色 | 结构怪、材质糊 | **AI 生成**（作者也已声明"内容由 AI 生成"） |
| 贴纸/图标/大字 | 色块干净、可复现 | **矢量/代码绘制** |
| 统一包装 | 字幕位置固定、字号体系一致 | 一套模板套所有页面 |

## 五、要做出同样效果，你只需做这一件事

**把"整屏卡片页"当成一种正式页面排进时间轴**（不是偶尔插一张），每 4–6 秒一个视觉重音：

1. 先按台词切"页面表"：哪几句该配**全屏卡**（提示词原文/清单/对比/数据）、哪几句给**真人**、哪几句配 **AI 素材 / B-roll**
2. 卡片全部**真字渲染**（统一字体字号）+ 统一白底卡样式
3. 卡片之间的切换用动效文字层的 `rise/pop`，不要转场特效
4. 真人在卡片页上**缩成小窗**持续存在（别整页消失，观众才不会"丢人"）

**按这套，kb2 建议加的三个插屏页**（各 4–6 秒）：
- 「提示词原文」卡 —— 讲到"提示词"时
- 「苏格拉底五问」卡 —— 123.3–144.4s（已在做）
- 「没想清楚 vs 想清楚」对比卡 —— 与开场钩子呼应
