## 3. 方形裁切（HD 1920×880 空间）

- **`crop=880:880:584:0`**（中心 x=1024 = 实测脸部中心）。
- 方形内实测纵坐标：**头顶 y≈22、下巴 y≈470、肩 y≈560、躯干底 y≈880**。

## 4. 人物缩放（定死：头高 184px）

- **880 → 361**（LANCZOS），缩放比 **k = 0.4107**（= 184/448，与第1篇同一比例）。
- 头部在成片里 **184px**（源 448px × 0.4107）。
- 抠像层（960×540）对应裁切：**`crop=440:440:292:0`**（= HD 坐标 ÷2）。

## 5. 圆窗参数

- **半径 r = 150px，圆心 (1090, 570)**（1280×720 输出坐标）。
  - 圆占 y 420–720、x 940–1240；**圆底边贴画框底边**。
  - 圆直径 300px = 画宽 **23.4%**。
- **圆窗层填充 = 源片纯白墙贴片**：`crop=400:400:150:180`（源片左上白墙区）→ 缩到 **320×320**。实测该区 RGB=(197,201,206)、std 4.5，极均匀。
- 圆层画布 320×320、落点 **(930, 410)**；圆遮罩在该层内 = 圆心(160,160)/r=150，边缘做 **1px 高斯**抗锯齿。
- ⚠️ **为什么必须用白墙贴片**：第2篇是紧口播，你肩膀宽 **872px**、几乎等于裁切框宽 → 任何放得下的圆都比人窄 → 若圆里放"胸前原片画面"，你的身子会把圆整块盖住（实测圆内白墙 0%），**圆框完全看不见**。第1篇能看见圆，是因为它取景松、圆里露出了原景。

## 6. 人物落点与遮罩（最容易做错的两条，Rio 必须照抄）

- 人物层（361×361）落点：**(909, 359)**（层底 = 画框底 720，贴底）。
- **人物遮罩 = `圆 ∪ (y < keep_y)`，其中 `keep_y = 人物层顶 + 470×k − 4 = 548`**
  （470×k = 下巴在层内的位置；即**分界正好压在下巴上**）。
- **只做 1.2px 高斯羽化**（给圆边抗锯齿）。
- 两条必须遵守的原因（都是踩过的坑，含实测数据）：

| 参数 | 错误取值 | 症状 | 正确取值 |
|---|---|---|---|
| 分界 keep_y | 612（下巴+60） | 分界~612 之间**圆外的肩膀被一并保留** → 右肩从圆里"露出来" | **548（下巴）** |
| 遮罩羽化 | 4px | 羽化把人物边界**向圆外糊出 4–9px 溢出带**（圆外 0–3px 环带 790 个衣服像素） | **1.2px**（环带降到 165，纯抗锯齿） |

  原理：分界压在下巴上 → 头部（头顶→下巴）整段无条件保留，**额头永远没有横线**；下巴以下交给圆裁，**肩膀不会伸出圆外**。两者同时成立。

- alpha 后处理（必做）：① 拉伸 `clip((a−35)/165, 0, 1)·255`；② **收边** `MinFilter(3)`（收 1px）；③ 轻羽化 0.6px；④ 底部 **25 行**渐隐（= 60×0.4107）。
- **去白边（unmultiply）**：原片背景是均匀白墙 W=(197,201,206)，对半透明边缘反解
  `C = α·F + (1−α)·W ⇒ F = (C − (1−α)·W) / max(α, 0.25)`，消除发丝/肩线上残留的白墙溢色。

## 9. 音频与输出

- 音频 = 原片原声，**AAC 128k**（全链只编码一次）。
- 视频 = H.264 **crf18** / preset veryfast / yuv420p / `+faststart` / 1280×720 / 30fps。
- **不要抬码率**：实测 crf18 与 crf15 的头部清晰度 216.2 vs 209.8（无增益、只涨体积 42%），crf18 已在质量天花板。

### L2 动画层（★ ）
1. 写 `plan_kb2.json`：每段一条 `{"start":0,"end":24.4,"images":["图集/b01_xx.jpg",…],"move":"in"}`
   （`move` = `in` 推近 / `out` 拉远 / `panL` 右→左移 / `panR` 左→右移 / `up` 下→上移）
2. `python3 mk_bg_kb2.py --plan plan_kb2.json --outdir bg_kb2`
3. 脚本自动做：每张图 → **机位A 中景**（zoom 1.0→1.14 缓推）+ **机位B 换角度**（从 1.30 起、换一种运镜），硬切拼接；输出 **1280×720 / 30fps / crf18 / +faststart**，并打印自查（分辨率·帧率·时长）+ 抽帧 `check_2s.jpg`。
4. 想加"轻微动作"就在提示词里写动作词（走、翻页、灯光变化），不要在后期硬加。

### L3 动效文字层（这一层是"看起来是动画"的关键）
1. 复制 `work/kb1/index.html` → 改名 `work/kb2/index.html`，**只改两处**：
   - `const W = 1280, H = 720, FPS = 30, DURATION = <全片秒数>;`
   - `const SPECS = [ … ]`：每条文案一个元素
2. 元素写法：`{ k:'s1_a', pos:[70,92], lines:[T('20+',132,900,THEME.num,'Bebas Neue')], enter:0.40, out:9.60, motion:'slideL' }`
   - `T(文字, 字号, 字重, 颜色, 字体)`；`motion` = `slideL`/`slideR`/`rise`/`pop`/`none`
   - `enter`/`out` 是**绝对秒**；`out:0` = 一直留到片尾
3. 渲染（在 `work/kb2/` 下）：
   - 静帧验证：`node render.mjs --variant A --times 6.5,20,55,90`
   - 全片序列：`node render.mjs --variant A --seq --from 0 --to <全片秒数>`
   - 输出 `out/A/motion/f_00001.png …`（**带透明通道**），合成时逐帧 `alpha_composite` 叠在动画层上
4. ⚠️ **必须做到"无页面报错"**（脚本会打印 `pageErrors`，非 0 就是有元素写错/字体没加载）。
5. ⚠️ 文字**不要压人物圆窗区**（右下角 940–1240 × 420–720）——会跟人打架；第1篇文字都在左半幅。
